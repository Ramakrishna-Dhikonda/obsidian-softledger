# Softledger tokens (v0.1.0)

Locked by Theme Lead for first CSS pass. Light is the hero; dark is a coherent twin.

## Surfaces
| Token | Light | Dark | Notes |
|-------|-------|------|-------|
| Canvas | `#F5F7F8` | `#1A1C1E` | Soft gray / soft charcoal workspace |
| Card / elevated | `#FFFFFF` | `#242628` | Floating panels, modals, settings |
| Subtle surface | `#EEF1F3` | `#2C2E30` | Nested chips, hover rows |
| Border (hairline) | `rgba(0,0,0,0.06)` | `rgba(255,255,255,0.08)` | Prefer shadow over hard borders |

## Accent & nav
| Token | Hex | Use |
|-------|-----|-----|
| Lime accent | `#A3E635` | CTAs, focus rings, positive, graph |
| Lime muted | `#D9F99D` | Soft success chips, hover wash |
| Forest (secondary) | `#14532D` | Gradients / deep contrast (sparingly) |
| Charcoal pill | `#2D2D2D` | Active tab / selected row (light) |
| Pill text | `#FFFFFF` | On charcoal or lime CTAs when needed |
